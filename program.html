Algoritma utama, baris demi baris

Inti algoritma ada di berkas tersendiri: tugas.py untuk Python, dan assets/algoritma.js sebagai terjemahan JavaScript yang dipakai seluruh situs. Program pengujiannya ada di eksperiment.py, yang memanggil fungsi dari tugas.py. Klik penjelasan di sebelah kanan untuk menyorot baris kodenya.

Jalankan program inti

Fungsi yang sama dijalankan di peramban. Keluarannya memakai format yang sama dengan python tugas.py, ditambah banyaknya evaluasi q yang selalu (n³ − n)/6.

Dari tiga loop ke (n³ − n)/6

Untuk setiap panjang l ada (n − l + 1) posisi awal i, dan setiap i mencoba (l − 1) titik belah k. Tabel ini menjumlahkannya untuk rantai di atas.

Menjalankan eksperiment.py

Simpan eksperiment.py satu folder dengan tugas.py, lalu jalankan dari terminal. Hasil lengkap ditampilkan di halaman Studi Kasus dan Perbandingan.

Perintah
python eksperiment.py python eksperiment.py --cepat

Mode lengkap butuh beberapa menit; --cepat memperkecil ukuran untuk mencoba.

Yang dibuktikan

Kemiringan log-log ≈ 3 (Θ(n³)), hasil DP = brute force pada semua n kecil, dan urutan optimal DP sama dengan pilihan numpy.multi_dot.
