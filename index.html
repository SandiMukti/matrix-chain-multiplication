Program inti · tugas.py

Seluruh algoritmanya hanya 27 baris

Fungsi matrix_chain_order mengisi tabel biaya m dan titik belah s dengan tiga loop bersarang. Berkas algoritmanya dipisah dari kode tampilan: tugas.py untuk Python dan assets/algoritma.js untuk situs ini.

  • Loop l — panjang subrantai, dari pendek ke panjang
  • Loop i — posisi awal, dengan j = i + l − 1
  • Loop k — titik belah; q = kiri + kanan + p[i−1]·p[k]·p[j]
Baca penjelasan baris demi barisUnduh tugas.py
def matrix_chain_order(p):
    """Mengisi tabel m dan s secara bottom-up (berdasarkan panjang rantai)."""
    n = len(p) - 1  # banyaknya matriks

    # Tabel berukuran (n+1) x (n+1) agar indeks 1..n sama dengan pseudocode;
    # baris/kolom 0 tidak dipakai.
    m = [[0] * (n + 1) for _ in range(n + 1)]
    s = [[0] * (n + 1) for _ in range(n + 1)]

    # Kasus dasar: m[i][i] = 0 (satu matriks tidak butuh perkalian).
    # Sudah terpenuhi karena tabel diinisialisasi dengan 0.

    # l = panjang rantai yang sedang dihitung, dari 2 sampai n
    for l in range(2, n + 1):
        # i = indeks awal rantai; rantai A_i..A_j dengan j = i + l - 1
        for i in range(1, n - l + 2):
            j = i + l - 1
            m[i][j] = math.inf  # nilai awal: belum ada solusi
            # k = posisi belah: (A_i..A_k)(A_{k+1}..A_j)
            for k in range(i, j):
                # biaya = biaya kiri + biaya kanan + biaya mengalikan dua hasilnya
                # hasil kiri berukuran p[i-1] x p[k], hasil kanan p[k] x p[j]
                q = m[i][k] + m[k + 1][j] + p[i - 1] * p[k] * p[j]
                if q < m[i][j]:   # simpan jika lebih murah
                    m[i][j] = q
                    s[i][j] = k
    return m, s

Cara kerja dalam tiga langkah

1 · Subproblem

m[i, j] = biaya minimum Aᵢ…Aⱼ

Rantai dipecah menjadi subrantai. Hanya ada n(n + 1)/2 subrantai berbeda, jadi setiap hasil cukup dihitung sekali dan disimpan.

2 · Pilih titik belah

Coba semua k di antara i dan j

Biaya = m[i, k] + m[k+1, j] + pᵢ₋₁·pₖ·pⱼ. Nilai terkecil disimpan, beserta k-nya di tabel s.

3 · Dari pendek ke panjang

Isi tabel per panjang rantai

Subrantai pendek selalu selesai lebih dulu, sehingga setiap nilai yang dibutuhkan sudah tersedia. Hasil akhir ada di m[1, n].
